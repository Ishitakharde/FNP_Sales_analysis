FNP Sales Analysis Dashboard | Excel Project Overview This project analyzes FNP (Ferns N Petals) sales data using Microsoft Excel. It presents key sales metrics and trends in an interactive dashboard to support data-driven business decisions. Tools & Skills

Microsoft Excel
PivotTables and PivotCharts
Data Analysis and Visualization
Interactive Slicers
KPI Reporting Dashboard Highlights
Total Revenue — overall revenue generated
Average Revenue — average revenue metric shown in the dashboard
Average Delivery Time — delivery performance metric
Monthly Revenue — revenue trends across months
Occasion-wise Revenue — comparison of revenue by occasion
City-wise Revenue — comparison of revenue across cities
Product Category Analysis — revenue by product category
Top Products — comparison of the top five products
Interactive Filtering — occasion slicer to explore the data Business Objective To turn sales data into an easy-to-understand dashboard that helps users explore revenue patterns, compare product and occasion performance, and identify areas for further business analysis. Project Files
FNP Sales analysis.xlsx — Excel workbook containing the dashboard, PivotTables, and source data sheets.
dashboard-preview.png — optional screenshot preview of the dashboard (if uploaded). How to Use
Download FNP Sales analysis.xlsx from this repository.
Open it in the desktop version of Microsoft Excel.
Use the dashboard slicer and explore the charts and PivotTables. Notes
Dashboard metrics reflect the values in the workbook and may change when the underlying data or filters are updated.
